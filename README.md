## 😩 The Problem

You just finished building something awesome.

You push it to GitHub, write a two-line README, and wonder why nobody stars it.

**The truth?** Most developers are amazing at writing code but terrible at presenting it. A bad README means:

- 😐 People visit your repo and leave in 10 seconds
- 🚫 No stars even if your project is genuinely great
- 👻 No contributors because nobody understands what it does
- 💼 Recruiters skip your portfolio because it looks unfinished

---

## ✅ The Solution

**README.forge** generates a complete, professional README from just a few inputs.

Fill in your project name, description, and tech stack — AI does the rest. Badges, tables, code blocks, installation steps, license info, contributing guide — all written and formatted perfectly.

```
Before README.forge         After README.forge
──────────────────          ──────────────────
# my-project                ⚫ MAEA OS — badges, hero, features table,
                            installation guide, tech stack, roadmap,
just a calculator app       license, contributing guide, author section
                            — all in 10 seconds ✅
```

## 🚀 Getting Started

### Option 1 — Fastest

1. Download `readme-generator.html`
2. Open it in any browser
3. Fill in your details
4. Click **⚡ Generate README**

### Option 2 — From Source

```bash
git clone https://github.com/markglenncomia8-byte/readme-forge.git
cd readme-forge
# Open readme-generator.html in your browser
```

---

## 🔑 Get Your Free API Key

README.forge uses **OpenRouter** to access NVIDIA Nemotron for free.

```
1. Go to openrouter.ai
2. Sign up — no credit card needed
3. API Keys → Create Key
4. Copy your key (sk-or-v1-...)
5. Paste into README.forge → Generate!
```

> **Free tier:** 200 requests/day · Completely free · No billing required
